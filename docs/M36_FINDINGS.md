## `0x101a2780` phone-feature builder

The synthesis caller invokes `0x101a2780` at `0x1010ce79`, returning to
`0x1010ce7e`. Its three cdecl arguments are feature record, previous regulated
descriptor and next regulated descriptor.

Recovered fields:

```text
feature +0x00  int32 count
feature +0x04  WORD interval_duration[count-1]
feature +0x18  WORD pitch_anchor[count]

descriptor +0x0c  node_count
descriptor +0x10  split_index
descriptor +0x14  source_position[]
descriptor +0xfb4  voicing[]
descriptor +0x1784 duration_q11[]
descriptor +0x1f54 pitch_q11[]
```

Recovered behavior includes:

- no-feature unity 2048 duration/pitch lanes;
- previous-right + next-left ownership;
- common duration Q11 from summed feature duration/source support;
- missing single pitch-anchor repair;
- reciprocal pitch interpolation through `0x101a2c00`;
- unvoiced/both-zero pitch forced to 2048;
- x86 truncation/wrap behavior including the 2047 fingerprint;
- `+3` feature-boundary tolerance;
- final next-left interpolation special case.

Portable reconstruction: `legacy_phone_features_m36()`.

`nicolai_m36_phone_probe` contains 259 deterministic cases. A Win32 x86 run
against the known original DLL is Gate A:

```json
{"portable_cases":259,"original_matches":259}
```

Static recovery of `0x10107c20` now covers:

- exact drop / cross / initial / deferred-terminal / ordinary dispatch order;
- ordinary-path checkpoint of cursor/selections;
- final dropped-step rollback gate and complete state transform;
- dropped-source bridging on the next ordinary first grain;

## Exact window cache topology

The old stateful adapter still uses an analytic M14 half-Hann approximation.
M36 statically recovers the actual cache built by `0x1010a020` and consumed by
`0x10109be0`.

Cache bounds are 20..400. Anchor lengths are:

```text
20, 24, 29, 35, 43, 52, 63, 77, 94,
115, 141, 173, 212, 260, 319, 392, 400
```

They are generated by repeated positive truncation of `current * 1.23` plus the
explicit final 400. Anchor windows use the original cosine/Q15 construction and
padding policy. Intermediate lengths are **packed pointer slices**, not freshly
computed Hann windows.

M36 also reconstructs the guarded runtime lookup domain 1..400:

- 20..399 direct cache pointers;
- 1..19 power-of-two decimation from cached packed data;
- 400 factor-2 expansion from the packed source selected by the original branch.

Implementation: `legacy_window_m36.*`; contracts: `legacy_window_m36_test.cpp`;
details: `M36_WINDOWS.md`.

Exact x87 `fcos` last-bit identity is not yet claimed; cache topology, integer
selection, padding and fallback routing are the recovered facts.
